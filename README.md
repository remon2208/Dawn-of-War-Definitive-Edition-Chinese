## 安裝

> [!IMPORTANT]
> 覆蓋前請先**備份原檔**，之後想還原比較方便。

1. 從上方按鈕或 [Releases](https://github.com/remon2208/Dawn-of-War-Definitive-Edition-Chinese/releases/latest) 下載你要的版本。
2. 把 zip **直接解壓縮到遊戲安裝資料夾**，選擇覆蓋。<br/>
   Steam 預設位置：`C:\Program Files (x86)\Steam\steamapps\common\Dawn of War Definitive Edition\`
3. 進遊戲，在設定中選擇對應的語言。

| 版本 | 下載檔案 | 會覆蓋的檔案 | 遊戲語言 |
|:--|:--|:--|:--|
| 繁體中文 | `Dawn-of-War-Definitive-Edition-Chinese-zh-TW.zip` | `Engine\Locale\Chinese\Engine.ucs`<br/>`Engine\Locale\Chinese\data\font\*.fnt`（13 個字型設定） | 繁體中文 |
| 簡體中文 | `Dawn-of-War-Definitive-Edition-Chinese-zh-CN.zip` | `Engine\Locale\SChinese\Engine.ucs` | 简体中文 |

### 還原

把備份的原檔放回去，或在 Steam 對遊戲按右鍵 →「內容」→「已安裝的檔案」→「驗證遊戲檔案的完整性」。

> [!NOTE]
> 遊戲更新或驗證檔案完整性時，可能會把檔案換回原版翻譯，屆時重新覆蓋一次即可。本修正只改文字檔，不影響存檔與連線對戰。

## 調整文字大小

繁中版會把介面字型統一設為 **25**（原版大多是 40，字偏大又不一致）。覺得太大或太小，可以自己改。

### 字型檔在哪裡？

字型設定檔放在遊戲安裝資料夾裡的：

```
Engine\Locale\Chinese\data\font\
```

**找到遊戲安裝資料夾的方法：**

1. 打開 Steam，進入「收藏庫」。
2. 在《Warhammer 40,000: Dawn of War – Definitive Edition》上按滑鼠右鍵 →「管理」→「瀏覽本機檔案」。
3. 會打開遊戲安裝資料夾，再依序點進 `Engine` → `Locale` → `Chinese` → `data` → `font`。

Steam 預設安裝位置的完整路徑是：

```
C:\Program Files (x86)\Steam\steamapps\common\Dawn of War Definitive Edition\Engine\Locale\Chinese\data\font\
```

> [!NOTE]
> 如果遊戲裝在其他硬碟（例如 `D:\SteamLibrary\`），路徑開頭會不一樣，用上面「瀏覽本機檔案」的方法最準確。

### 用記事本修改

1. 打開上面的 `font` 資料夾，裡面有 13 個 `.fnt` 檔。
2. 對其中一個 `.fnt` 檔按右鍵 →「開啟檔案」→ 選「記事本」，會看到像這樣的內容：

   ```
   sizeDefault  = 25;
   size640      = 25;
   size800      = 25;
   ...
   size3840     = 25;
   ```

3. 把 `sizeDefault` 和 `size640`～`size3840` 這 10 行的數字都改成你要的大小，存檔。
4. 13 個 `.fnt` 檔都照做，然後重新啟動遊戲。

> [!TIP]
> 數字越大字越大，一般建議 **22～30**。螢幕解析度高（2K、4K）可以調大一點，筆電小螢幕可以調小一點。

<details>
<summary><b>進階：用 PowerShell 一次改完 13 個檔案</b></summary>

<br/>

1. 先照上面的方法打開 `font` 資料夾。
2. 點一下檔案總管上方的**網址列**，輸入 `powershell` 後按 <kbd>Enter</kbd>，會在這個資料夾開啟 PowerShell 視窗。
3. 貼上下面這行，把開頭的 `25` 換成你要的數字，按 <kbd>Enter</kbd> 執行：

   ```powershell
   $n = 25; Get-ChildItem *.fnt | ForEach-Object { (Get-Content $_.FullName -Raw) -replace '(size\w+\s*=\s*)\d+', "`${1}$n" | Set-Content $_.FullName -NoNewline -Encoding ascii }
   ```

4. 沒有出現紅字就是改好了，重新啟動遊戲即可。

</details>
